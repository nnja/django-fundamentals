# Photo credits

The sample animals' photos. `uv run manage.py seed` copies each one into the
media folder for the animal whose row in `ANIMALS` names it. Each photo is
cropped and resized to 800 by 600 and saved as WebP.

The photos aren't covered by the project's MIT license: each keeps the license
in its row.
